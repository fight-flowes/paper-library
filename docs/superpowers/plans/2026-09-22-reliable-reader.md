# Reliable personal reader implementation

Approved scope: local single-user modular monolith. Implement durable content history and verifiable backup/restore, resilient worker execution, search and personal reading records, and operational diagnostics. No multi-user service or external infrastructure.

1. Add storage primitives: maintenance shared/exclusive gate, content-addressed paper revisions, verified backup manifests, SQLite online backups, restore preview and restoration into a new empty directory. Exclude credentials, derived caches and locks; preserve originals, translations, jobs, uploads and personal records. Restored jobs pause rather than running unexpectedly. Automatic backup is a daily systemd user timer using the same CLI, not an opaque server thread. No destructive live restore.
2. Make workflow and terminal writers cooperate with maintenance gate. Add paper-level mutation exclusion, worker recovery attempt budget and durable stage events. Recover only after coordinator lock acquired. Fix conditional state writes so cancellation/heartbeat cannot be overwritten. Graceful worker shutdown releases resumable work rather than marking cancelled. Existing manual retries remain available.
3. Personal SQLite store: indexed title/author/original/translation substring search, reading location, bookmarks, highlights and editable notes, JSON/Markdown export. Text selectors include quote/context/version; changed texts get unique relocation or explicit orphan status. Server writes require existing management token and same-origin policy. No model/network dependency for reading/search.
4. Frontend search, personal reading shelf and paper notes panel. Debounced progress, explicit continue-reading action, selection-based highlights and notes. Safe text rendering and small-screen layouts. Do not wrap or mutate formula/translation DOM for highlights; CSS Highlight API when supported, note list works without it.
5. Operations: local status page and CLI health probes separating core reading availability from optional model/MinerU/Tavily availability, bounded/redacted structured logs and durable job stage events. Document user systemd service/timer, backup retention, upgrades and rollback rehearsal.
6. Test new persistence and error paths first; run whole Python suite and browser checks. Snapshot actual library and restore into temporary directory, compare checksums/databases, never replace live data during verification. Reindex real library and verify actual reading UI.
