# 逐段中文对照翻译实施计划

目标：保留英文论文，在各段下方按需显示中文译文；不改动原始 Markdown。
已确认：使用 event-platform/.env 的 QWEN38_EXTERNAL（qwen3.8-27b），不随活动配置切换。

实施步骤：
- [x] 从 Markdown token 构造翻译单元和稳定标识，在段落、标题、列表文本、Markdown 表格单元后插入译文位置。
- [x] 保护公式、代码、链接、图片及行内格式，校验模型返回的占位符，所有生成文本按纯文本转义。
- [x] 后端读取指定配置，通过兼容 chat/completions 的接口翻译；禁用思考，不自动回退其他模型。
- [x] SQLite 单独缓存译文，缓存键包含库、论文、正文版本、接口、模型和翻译协议版本。
- [x] GET 返回段落与已缓存译文；POST 仅接受服务器已知段落 ID 和正文版本。限制并发并返回可恢复的错误。
- [x] 前端提供中英对照开关，逐段显示进度、停止/继续和失败重试；无服务时保留原文。
- [x] 增加解析、模型响应、缓存、跨库隔离和页面交互测试，使用假模型接口，不连接尚未部署的真实模型。
- [x] 更新使用说明并验证现有阅读功能。

实现文件：reader/translation_segments.py、translation.py、translation_routes.py；现有 renderer、app、paper 模板及静态资源。
第一版原样保留独立公式、代码块和原始 HTML 表格；文本段落、标题、列表与 Markdown 表格单元支持对照。

验证：132 项 Python 测试通过，2 项子测试通过；Playwright 验证逐段位置、数学与代码保留、表格、开关、缓存、移动布局、服务不可用、超长段落跳过及暂停/继续。实际 5 篇论文的页面与翻译单元一致。未调用真实模型。
