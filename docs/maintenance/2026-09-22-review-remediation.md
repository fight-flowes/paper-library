## 部署边界

仍为本地单用户应用，没有改造成公网多用户产品。本轮验证覆盖回归、故障注入、单页实际解析和隔离恢复；未进行长时间负载或逐篇人工校订。模型判断仍可能有误，结构文件存在不代表所有段落/标题在学术意义上完全正确。

已支持第二备份目录，但没有凭空指定另一块磁盘或远程存储，当前实际备份仍在本机。CI 文件位于项目自己的 `.github/workflows/check.yml`；当前 Git 根目录属于更外层的多项目工作区，自动触发需在实际托管仓库接入。本文不将这些配置支持描述为已启用异地备份或已运行远程 CI。


后续同步更新：项目已建立独立 Git 仓库，目标为 `fight-flowes/paper-library`，CI 定义随项目推送；上面的外层仓库接入限制描述的是整改验收时的历史状态。

同步范围：按用户后续明确选择，GitHub 只上传代码、测试、文档和空论文库示例，现有 `libraries/` 全部排除，7 篇论文仍保留在本地。
